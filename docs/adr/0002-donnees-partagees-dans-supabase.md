# Données partagées dans le cloud, sur Supabase

Les deux membres doivent voir leurs données respectives depuis deux plateformes (Android et iPhone). Les données ne peuvent donc pas rester sur un seul téléphone. On les stocke dans une base Supabase gratuite, avec une connexion par email.

Remplacée par l'ADR-0003 : la membre ne veut pas de base de données externe.
